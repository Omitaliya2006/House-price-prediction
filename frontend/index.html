How it works

From your entries to a price

Every estimate travels the same four-step survey — the exact pipeline used when the model was trained.

  1. 01

    You enter details

    Twelve features describe the house — size, rooms, and yes/no amenities like air conditioning.

  2. 02

    Preprocessing

    Numbers are scaled and text answers become 0/1 columns, so the model receives clean, all-numeric data.

  3. 03

    The model predicts

    A Gradient Boosting model — many small decision trees working together — estimates the price.

  4. 04

    You see the estimate

    The predicted price is sent back and shown here, instantly.

About the project

A student project, built end to end.

Plat is a supervised machine-learning web application. A regression model is trained on a housing dataset, saved as a reusable pipeline, and served through a FastAPI backend. This site is the front door: it collects a house's details, sends them to the API, and displays the model's estimate.
